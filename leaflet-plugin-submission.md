description: >
  A drag-and-drop GUI control that lists all map panes (sorted by z-index) and
  the layers within each pane. Panes and layers can be reordered by dragging,
  and the underlying CSS z-indices / DOM order are updated automatically.
  Supports custom panes, tile layers, markers, path layers, and image overlays.
  Fires <code>panereorder</code> and <code>layerreorder</code> events on the map.
