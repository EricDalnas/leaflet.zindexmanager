Leaflet.ZIndexManager

Drag-and-drop z-index management for map panes and layers

How to use

1

Open the control

Click the ☰ stack icon in the top-right corner of the map to open the Z-Index Manager panel.

2

Inspect panes & layers

Each row with a grey background is a map pane. Layers are listed beneath their pane, indented. Badges show: z:400 CSS z-index, tile polygon layer types.

3

Reorder panes

Drag the ⠿ handle on a pane row to move that pane up or down. A blue line shows the insertion point. The CSS z-indices are redistributed automatically.

4

Reorder layers

Tile layers can be dragged by their ⠿ handle, which reassigns their zIndex. Other layer types aren't reordered here; pass enableMoveToFrontSendToBack: true to the control to add move-to-front/back buttons for them.

5

Change z-index from code

Use the Change pane z-index panel below to set pane.style.zIndex directly. The manager panel updates live to reflect the change, even though it didn't trigger it.
